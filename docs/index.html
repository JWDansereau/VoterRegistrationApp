01 • Project Overview

From requirements to a working application

The Voter Registration Web Application was developed as the Senior Project II capstone project. It provides a web-based workflow for creating user accounts, submitting voter registration information, checking registration status, and allowing administrators to review registrations.

The project was developed iteratively with ASP.NET Core MVC, C#, .NET 10, Entity Framework Core, SQL Server LocalDB, Bootstrap, Visual Studio, and Git/GitHub.

Project Goal

Demonstrate practical software-development skills through a complete MVC application including database persistence, authentication, role-based access, CRUD operations, testing, documentation, and source control.

04 • Architecture & Design

MVC application architecture

Application Structure

  • Controllers: handle requests and application workflows.
  • Models: represent users, registrations, database context, and errors.
  • Views: provide the Razor-based user interface.
  • Entity Framework Core: provides database access and migrations.
  • Session state: supports custom authentication and role checks.

Database Design

The application uses Users and VoterRegistrations data sets. Registration records are associated with users through UserID, allowing the status workflow to identify the logged-in user's registration.

Supporting design artifacts: The final CST-452 Architecture and Design document contains the project's architecture, ER/database, UML, UI, sequence, and application-flow diagrams.

07 • Run the Project

Getting the application running

  1. Clone or download the VoterRegistrationApp repository.
  2. Open the solution in Visual Studio.
  3. Restore NuGet packages.
  4. Ensure SQL Server LocalDB is available.
  5. Run Update-Database if the local database has not been created.
  6. Run the application from Visual Studio.
